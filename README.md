# MechOS

A bilingual (Persian/English) Android toolbox for mechanical engineering students.

## Features
- Persian / English interface
- Dark and light themes
- Engineering calculator
- Starter formula library for mechanics and thermodynamics

## Build
Open this repository in Android Studio, or run `gradle assembleDebug` with JDK 17 and Android SDK 35 installed. GitHub Actions builds a debug APK on every push to `main` and uploads it as `MechOS-debug-apk`.

Package: `com.mechnos.app`
